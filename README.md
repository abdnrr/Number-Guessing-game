#  Java Number Guessing Game

A simple, interactive command-line application built in Java where the user tries to guess a randomly generated number between 1 and 100 with dynamic hints and attempt tracking.

---

##  Features

- **Random Number Generation:** Generates a secret number between 1 and 100 using `java.util.Random`.
- **Interactive Console Input:** Accepts user guesses using `java.util.Scanner`.
- **Dynamic Hints:** Provides immediate feedback (`too high` / `too low`) to guide the player.
- **Attempt Tracker:** Counts and displays the total number of attempts upon winning.

---

##  Concepts Demonstrated

- **Control Flow:** Implementation of `do-while` loops and `if / else if / else` conditional statements.
- **Java Utilities:** Usage of standard libraries (`java.util.Scanner` and `java.util.Random`).
- **Resource Management:** Proper closing of input streams (`scanner.close()`).
